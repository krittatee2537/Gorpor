Chrome extension (แผงด้านข้าง) สร้างคลิปสั้นแนวตั้ง ด้วยสคริปต์จาก Gemini + เสียงพากย์ไทย + ซับไตเติล พร้อมคิวโพสต์ TikTok

🌐 เปิดเว็บแอป   ⬇️ ดาวน์โหลด extension
ติดตั้ง
  1. แตก zip
  2. เปิด chrome://extensions เปิด Developer mode
  3. Load unpacked เลือกโฟลเดอร์ที่แตกไว้
  4. ใส่ Gemini API Key ที่แท็บตั้งค่า
